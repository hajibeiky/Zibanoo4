# زیبانو (ZIBANO) — سامانه هوشمند جستجو، مقایسه و رزرو آنلاین آرایشگاه

**پروژه فاز اول درس تجارت الکترونیکی — دانشگاه یزد**  
**شعار اصلی:** «زیبانو؛ انتخاب آگاهانه، رزرو آسان»

---

## ۱. معرفی پروژه

زیبانو یک پلتفرم یکپارچه وب برای جستجو، مقایسه قیمت و خدمات، مشاهده نمونه‌کارهای دسته‌بندی‌شده و ثبت درخواست رزرو آنلاین آرایشگاه‌های زنانه و مردانه در سراسر ایران است.  
همچنین این سامانه دارای لاین اختصاصی «خدمات در محل» ویژه سالمندان، بیماران، مصدومان و افراد پرمشغله است که بر اساس یافته‌های مصاحبه میدانی در شهر یزد کشف و طراحی شده است.

این پروژه مطابق با سرفصل و الزامات فاز اول درس تجارت الکترونیکی شامل دو بخش بنیادین است:
1. **پرونده تحلیلی کسب‌وکار (بخش الف):** تبیین اصطکاک‌ها، ارزیابی ایده با پرسش‌های هشت‌گانه، طبقه‌بندی ایده ترکیبی، مدل بصری اتلاف زمان و هزینه، گزارش مصاحبه‌های میدانی و نقشه سفر مشتری.
2. **محصول اولیه قابل‌آزمایش (MVP - بخش ب):** وب‌اپلیکیشن کاربردی و عملیاتی با قابلیت ناوبری دوگانه، سناریوی واقعی رزرو آنلاین، مقایسه همزمان چند سالن، فیلتر شهرها، پیگیری نوبت‌ها و پنل آزمایشی آرایشگر.

---

## ۲. امکانات و قابلیت‌های پیاده‌سازی‌شده

### بخش محصول اولیه (MVP):
- **صفحه اصلی تجاری و جذاب:** طراحی اختصاصی با لوگوی مینیمال زیبانو، رنگ‌بندی لوکس (بنفش عمیق، طلایی مات، یاسی، کرم و ذغالی)، معرفی تفکیک‌شده لاین بانوان و آقایان، ۸ مزیت رقابتی، آرایشگاه‌های منتخب و تایم‌لاین ۴ مرحله‌ای.
- **موتور جستجو و فیلتر پیشرفته:** فیلتر بر اساس نام سالن، شهرها (یزد، تهران، اصفهان، شیراز، مشهد، تبریز و...)، جنسیت، نوع خدمت، رده قیمتی و خدمات در محل.
- **مقایسه تطبیقی چند آرایشگاه:** امکان انتخاب و مقایسه رو در روی ۲ تا ۳ سالن در یک جدول مقایسه‌ای استاندارد.
- **صفحه اختصاصی هر آرایشگاه:** شامل گالری تصاویر، آدرس، ساعات کاری، لیست شفاف تعرفه‌ها، آلبوم نمونه‌کارهای تفکیک‌شده و شرایط اعزام آرایشگر به منزل.
- **سناریوی کامل رزرو آنلاین نوبت:** انتخاب خدمت، تقویم تعاملی، انتخاب سانس آزاد (با جلوگیری از رزرو تکراری و تداخل)، ثبت مشخصات و شماره موبایل با اعتبارسنجی و صدور کد رهگیری اختصاصی (`ZB-XXXXX`).
- **ذخیره‌سازی پایدار (LocalStorage):** تمام تغییرات، درخواست‌های رزرو و ویرایش‌های پنل در حافظه مرورگر حفظ می‌شوند.
- **پنل آزمایشی آرایشگر:** مشاهده اطلاعات سالن، ویرایش ساعات کاری، افزودن خدمات و قیمت جدید، افزودن نمونه‌کار و تغییر وضعیت درخواست‌ها (تأییدشده / ردشده).
- **پیش‌نمایش مفهومی هوش مصنوعی در آینده:** معرفی شفاف و علمی زیرساخت آینده مدل‌های هوش مصنوعی (Google AI Studio) برای شبیه‌سازی مدل مو روی چهره کاربر مطابق با پاسخ پرسش هفتم گزارش.

## ۴. نحوه نصب و اجرای پروژه

### پیش‌نیازها:
- Node.js (نسخه ۱۸ یا بالاتر)
- npm یا pnpm

### مراحل اجرا:

۱. کلون یا باز کردن پوشه پروژه:
```bash
cd zibano-app
```

۲. نصب وابستگی‌ها:
```bash
npm install
```

۳. اجرای سرور توسعه محلی:
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

۴. ساخت نسخه نهایی جهت انتشار (Production Build):
```bash
npm run build
```
خروجی نهایی در پوشه `dist` ایجاد شده و به راحتی روی Vercel یا GitHub Pages مستقر می‌شود.
